# Learning Philosophy

This project favors useful repetition over academic completeness.

Principles:

- practice language that will actually be used in Costa Rica
- revisit high-value structures often
- combine reading, writing, speaking, and listening
- keep correction actionable and emotionally manageable
- build confidence through realistic repetition

The true beginner needs clarity and momentum. The more advanced learner needs realism and refinement. The system should support both without fragmenting into two totally separate products.
