# Handoff Summary Template

Use this template when closing a steward thread or opening a new one from a prior handoff.

Keep it short enough to read in one screen.

## Handoff Date

- `YYYY-MM-DD`

## Steward Thread

- Current thread: `name or short label`
- Active milestone/workstream: `name`
- Reason for handoff: `milestone boundary, context reset, subsystem shift, user redirect, other`

## Current Objective

- `one-sentence description of the work the steward thread was responsible for`

## Branch And Latest Commit

- Branch: `branch-name`
- Latest commit: `short-sha and message`
- Workspace state: `clean` or `dirty`

## Subagent Status

- Subagents used: `list agent roles or say none`
- If none: `brief reason the work was not meaningfully parallelizable`
- Remaining parallelizable work for next steward: `optional`

## What Changed

- `high-signal change 1`
- `high-signal change 2`
- `high-signal change 3`

If no files changed:

- `inspection/review only; no code or docs changed`

## Verification

- `check run and result`
- `check run and result`
- `not run: anything intentionally skipped`

## Blockers And Risks

- `current blocker or none`
- `current risk or caveat`

## Decisions And Assumptions

- `decision already made`
- `assumption currently in force`
- `explicit not-now item if relevant`

## Next Recommended Action

- `single best next step for the next steward`

## First File Or Command For Next Steward

- First file: `/absolute/path/to/file`
- First command: `command if helpful`

## Short Handoff Summary

`Write a 3-7 sentence summary covering what changed, what is stable, what is still open, and what the next steward should do first.`
