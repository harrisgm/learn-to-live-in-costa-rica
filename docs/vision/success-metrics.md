# Success Metrics

## Product Outcomes

- Users can run the app on a local network with a shared backend and Postgres persistence.
- Users can paste or type Spanish and receive useful structured feedback.
- Both learners can use the system at the same time from different devices.
- Sessions can be reviewed later to spot recurring mistakes.
- The repo stays clean enough that new learning assets can be added quickly.
- Speech features can be layered on without breaking the text-first correction flow.

## Learning Outcomes

- Users can complete weekly conversation practice with increasing confidence.
- Users can recognize and fix recurring grammar and phrasing mistakes.
- Users can navigate common Costa Rica life scenarios with less hesitation.
- Users improve at understanding natural-speed Spanish through repeated exposure.

## Repo Health

- Docs match current behavior.
- Public assets stay sanitized and reusable.
- Private learner data remains outside version control.
- New contributors can get the app running in under 15 minutes.
- The architecture stays portable enough to support a future iPhone/native client if needed.
