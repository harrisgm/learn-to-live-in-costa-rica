# Mission

Learn to Live in Costa Rica exists to help an American couple build practical Spanish fluency for real life in Costa Rica over the next three years.

This is not an academic language-learning project first. It is a living, usable system that should improve:

- reading of everyday Spanish
- writing of messages, notes, and practical communication
- spoken confidence
- comprehension of natural-speed local speech
- readiness for Costa Rica-specific situations

The product should work well on a local network for both learners at the same time, with a shared backend and durable Postgres-backed session data. The app should grow from a text-first coaching experience into speech-aware workflows without making speech a blocker for the core learning loop.

The product should make progress visible, reduce overwhelm for the true beginner, and still challenge the more advanced partner with natural phrasing and realistic roleplay. It should also remain adaptable to a future iPhone/native client if that path becomes valuable later.
