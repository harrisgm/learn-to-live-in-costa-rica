# Feedback Rules

The coaching system should give feedback in this order:

1. Preserve the learner's meaning.
2. Correct only what improves clarity, grammar, or naturalness.
3. Return structured fields, not just prose.
4. Explain the main issue in plain English.
5. Offer one natural version, not five competing rewrites.
6. Provide one retry prompt and one follow-up prompt.
7. Highlight recurring error tags for review.
8. Encourage forward motion instead of overloading the learner.

Additional guidance:

- Beginner mode should correct gently and explain explicitly.
- Naturalization mode should prioritize phrasing, register, and rhythm.
- Couple mode should help both users keep the exchange going.
- Costa Rica mode should prefer locally useful vocabulary and realistic context.
- Speech input should feed the same contract as text, with the transcript shown explicitly.
- Error tags should be typed and severity-marked so mistake review stays machine-usable.
