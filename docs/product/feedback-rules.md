# Feedback Rules

The coaching system should give feedback in this order:

1. Preserve the learner's meaning.
2. Correct only what improves clarity, grammar, or naturalness.
3. Explain the main issue in plain English.
4. Offer one natural version, not five competing rewrites.
5. Highlight recurring error tags for review.
6. Encourage forward motion instead of overloading the learner.

Additional guidance:

- Beginner mode should correct gently and explain explicitly.
- Naturalization mode should prioritize phrasing, register, and rhythm.
- Couple mode should help both users keep the exchange going.
- Costa Rica mode should prefer locally useful vocabulary and realistic context.
