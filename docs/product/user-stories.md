# User Stories

## Beginner Learner

- As a true beginner, I want clear correction in English so I understand why my Spanish was changed.
- As a beginner, I want slower, simpler prompts so I can build confidence before responding freely.
- As a beginner, I want recurring mistakes tracked so I can review the patterns that keep blocking me.

## More Experienced Partner

- As a learner with basic survival Spanish, I want naturalization feedback so I can stop sounding overly literal.
- As the stronger partner, I want harder roleplay scenarios so I can practice beyond tourist Spanish.
- As a partner, I want couple mode so we can practice together without needing a third person present.

## Shared Needs

- As future residents, we want Costa Rica-specific scenarios like housing, banking, neighbors, and contractors.
- As learners preparing for daily life, we want vocabulary packs tied to realistic situations.
- As a couple, we want the app to stay simple enough to use consistently.
